# C6：J280 字形闭环修正版

本包面向 J280 的 GW2A-LV55PG484C8/I7，固件身份为 `0x56354336`。本轮没有连接、烧录或驱动实物。ModelSim 与 Simulink 使用既有代表性模型验证；它不是已辨识的实物模型。

## 本次改动

- 保留 PID 默认值：角度 49/0/251，位置 25/0/610，周期分别为 5/25 ms。
- 文字轨迹显式使用半速输入与模型输入前馈补偿；普通手绘、固定轨迹和保持路径保留模式 0。
- GOWIN 的输入节点、执行时间和字形保持本轮已经确认的版本，CRC 为 `8FC95613`。
- EasyStart 改用 R3 单线输入字形，增加字母间距、y 的下伸笔画和 t 的横画。名义宽度 160 计数，508 个 Q4 节点，CRC 为 `4A124384`。节点由 MATLAB 离线生成；上位机和 FPGA 不运行字形优化求解器。
- 所有图中的实测曲线均由反馈编码器计算。保留整数台阶和丢帧，不把目标字形覆盖到反馈曲线上。

## 运行与配套

在安装有 Python 3 和 Tk 的电脑上，从本目录运行：

```powershell
python -B host/app.py --variant 5
```

串口依赖随 `host/vendor` 提供。窗口只接受 C6 身份；旧 C5 位流不能被当作 C6 使用。已有配套固件和上位机必须成套保留，不能混用。不要用本包的旧历史单元测试名称推断固件版本。

上传是独立的数据暂存，不会自动 ZERO、RUN、起摆或播放。完成上传、提交和字段 0/1/2/3/4/7 的独立读回后，仍需明确播放。当前要求是不烧录，因此本轮不进行这些实物操作。

## 验证边界

输入前馈系数由给定模型和默认 PID 推导，不是实物参数识别，也不是自适应学习。更换机械结构、负载、PID 或采样延迟后必须重新验证。联合仿真保留 5 ms、一个采样周期的接口延迟及真实 RTL 运算，但未模拟整板 ADC 采样窗口、PWM 电气行为或电机摩擦。

原 ADC、编码器、PWM、安全逻辑、CST 和 SDC 未改。新的文字输入仍满足原 512 点、位置、累计行程、速度、加速度、jerk 和任务时限约束。详细结果以交付包的验证报告及原始 WLF/MAT/CSV 为准。
