# 功能代码分类

本目录按功能整理，用于私密仓库 [lcg8117-jpg/fpga-lab](https://github.com/lcg8117-jpg/fpga-lab) 的源码归档。仓库必须保持 Private；不得改为公开或擅自扩大访问权限。

当前画字已成功，效果较好，依据你在 2026-11-04 的现场确认记录。

## 整理结果

- 保留 1,305 个源码和配套资料文件，各功能来源独立，未合并修改。
- 不含任何 `.fs` 文件、其他固件镜像、EXE/DLL、捆绑运行时或嵌套压缩包。WLF、MAT、CSV 等原生波形数据保留。
- 电脑蓝牙端与六位置控制完整包中的电脑端内容逐文件一致；分别保留其来源，详见[重复关系核对](00_分类说明/Bluetooth_Duplicate_Comparison.json)。
- 原始压缩包和原项目保留不变。此目录是分类后的源码与资料集合；原启动器可能仍引用已排除的运行时或位流，整理时没有运行烧录或设备控制脚本。
- 后期字形映射显示版仅在索引中记录原位置，未混入真实坐标源码。原文档与旧清单作为来源记录保留；本目录的实际内容以[新文件清单](00_分类说明/source_manifest.json)和[核验报告](00_分类说明/VERIFICATION.json)为准。
