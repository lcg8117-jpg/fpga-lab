V4 R28 蓝牙电脑端（Windows10/11，64位）
固件：56345239；schema56345208；wire4/layout5。
角度P/I/D：53.78 / 0 / 210.14；位置：17.67 / 0 / 616.61。
角度P/D周期1ms/5ms；位置P/D周期5ms/25ms；积分固定0。

电脑端代码、Python3.12、Tk/Tcl、Bleak和WinRT依赖均已自带，无需安装Python或pip；程序不需要模型API或AI调用。
电脑需要有支持BLE的蓝牙适配器并开启蓝牙。程序通过BLE GATT连接BT10，不选COM串口，不默认USB。

使用：
1. 把整个ZIP完整解压到可写目录（建议D盘）；不要在压缩包内运行，也不要只复制一个.py或.cmd。所在盘需至少10GiB可用空间，保留现有日志保护。
2. 同一个BT10换电脑时，先在旧电脑窗口点“断开并停止”，再让新电脑连接，避免同时占用同一模块。
3. 给板卡/BT10上电，双击根目录“启动蓝牙窗口.cmd”，然后在窗口点击“连接”。打开窗口不会自动连接、校零或运行。
4. 当前这块BT10默认地址D0:54:7B:AA:0C:84；同一模块换电脑无需改地址，若换蓝牙模块则需核对并填写其地址。
5. 窗口核验FW56345239并显示实际参数后，保持停止，扶直摆杆点“扶直校零”；校零有效后再手动点“开始平衡”。

功能：平衡、六位置、STOP、校零、停机改参/独立读回、实际位置与角度误差波形、压缩日志。
六位置按钮按当时实测位置为原点，相对增加60/120/180/240/300/360度，不是六个绝对方位。
控制算法在FPGA运行；电脑用于连接、操作、读写参数和显示记录。

蓝牙收发实现：PC_Bluetooth/client.py、ble_transport.py、bt10_windows_select.py、bt10_profile.py、protocol.py；界面app.py。
启动失败时查看PC_Bluetooth/logs/startup_error.log或startup_stderr.log；连接失败先核对旧电脑是否断开、设备供电、蓝牙开启和地址。
板端实际参数/身份不匹配时保留原来的拒绝保护，不屏蔽超时、错误或停机逻辑。

验证边界：本机已实际通过该BT10蓝牙连接FPGA并独立读回六个新参数；另一台电脑的蓝牙硬件/驱动尚未现场实测。包会执行解压换路径的离线与窗口启动验证。
